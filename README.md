
# CAMPUS
### 제휴 가게 통합 제공

## 1. 프로젝트 소개

CAMPUS는 학교 내 단과대학 및 동아리별로 분산되어 있는 제휴 가게 정보를 하나의 웹사이트에서 확인할 수 있도록 하는 프로젝트이다.

학생들이 각 단과대학과 동아리의 제휴 가게 위치, 할인 혜택 및 이용 조건을 편리하게 확인할 수 있도록 하여 정보 접근성과 편의성을 높이는 것을 목표로 한다.

## 2. 주요 기능

- **제휴 가게 지도:** 학교 주변 제휴 가게의 위치를 지도에 표시
- **제휴 단체별 구분:** 단과대학 및 동아리별 색상과 필터를 활용하여 제휴 가게 구분
- **가게 검색 및 필터:** 가게명, 업종, 제휴 단체별 검색 기능
- **제휴 혜택 안내:** 가게별 할인 혜택, 이용 조건 및 제휴 대상 확인
- **반응형 웹페이지:** PC와 모바일에서 편리하게 이용할 수 있는 화면 제공

## 3. 팀원별 역할

| 역할 | 인원 | 주요 업무 |
|---|---|---|
| 조장 | 1명 | GitHub Repository 관리, Issue·PR 관리, 프로젝트 총괄 및 코드 통합 |
| 디자인 | 1명 | 웹사이트 UI/UX, CSS 및 반응형 디자인 |
| 제휴 가게 정보 | 2명 | 단과대학·동아리 제휴 자료 조사, 데이터 정리, 검색·필터 및 상세 정보 구현 |
| 지도 | 1명 | 지도 연동, 제휴 가게 위치 표시 및 제휴 단체별 마커 구분 |

## 4. 개발 방향

HTML, CSS, JavaScript를 기반으로 웹사이트를 개발하고, GitHub를 활용하여 팀원별 역할을 분담하고 협업할 예정입니다.
